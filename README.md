# CampusBite

Сервіс для перегляду меню, попереднього замовлення та оплати страв в університетській їдальні через QR-код без черги.

Репозиторій командного проєкту в межах курсу «Управління проєктами» (Лабораторна робота №1 — ініціалізація командного проєкту).
